End-to-End Architecture

How the Full NexvorS3 Flow Works

From your application or media player down to zero-allocation disk storage and backup recovery.

1

Clients & Apps

AWS SDK, AWS CLI, mobile/web video players, or browsers connect via HTTP/REST or open port :9001.

2

Router & Auto-UI

Port :9000 serves S3 XML/JSON APIs and auto-redirects browsers (307) to the MinIO-style Console on :9001.

3

Auth & Security

Constant-time SigV4 verification, path-traversal sanitizer, Slowloris guard, and (in Pro) IAM RBAC & Ed25519 license check.

4

256-Shard Concurrency

FNV-1a striped locks + sync.Pool 128KB buffers let hundreds of streams read/write in parallel with zero GC stalls.

5

Disk & Streaming

Saves objects + SHA-256 metadata, streams video chunks via HTTP 206 Partial Content & HLS, and exports ZIP backups.

Developer Experience

Start Storing & Streaming in 10 Seconds

Copy any snippet below to spin up NexvorS3 and connect your existing applications.

docker run -d \
  --name nexvor-s3 \
  -p 9000:9000 \
  -p 9001:9001 \
  -v nexvor_data:/data \
  -e NEXVOR_ROOT_USER=admin \
  -e NEXVOR_ROOT_PASSWORD=strongpassword123 \
  dinidun/nexvors3:latest

# Web Console UI: http://localhost:9001 (port 9000 auto-redirects browsers)
# S3 REST API:    http://localhost:9000
services:
  nexvors3:
    image: dinidun/nexvors3:latest
    container_name: nexvor-s3-server
    restart: unless-stopped
    ports:
      - "9000:9000"  # S3 REST API
      - "9001:9001"  # Web Console UI
    environment:
      - NEXVOR_ROOT_USER=minioadmin
      - NEXVOR_ROOT_PASSWORD=minioadmin
    volumes:
      - nexvor_data:/data

volumes:
  nexvor_data:
export AWS_ACCESS_KEY_ID=minioadmin
export AWS_SECRET_ACCESS_KEY=minioadmin

# Create bucket
aws --endpoint-url http://localhost:9000 s3 mb s3://media-bucket

# Upload video / HLS assets
aws --endpoint-url http://localhost:9000 s3 cp movie.mp4 s3://media-bucket/
aws --endpoint-url http://localhost:9000 s3 cp stream.m3u8 s3://media-bucket/

# List objects
aws --endpoint-url http://localhost:9000 s3 ls s3://media-bucket
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  region: "us-east-1",
  endpoint: "http://localhost:9000",
  forcePathStyle: true,
  credentials: {
    accessKeyId: process.env.NEXVOR_ROOT_USER || "minioadmin",
    secretAccessKey: process.env.NEXVOR_ROOT_PASSWORD || "minioadmin",
  },
});

await s3.send(new PutObjectCommand({
  Bucket: "videos",
  Key: "demo.mp4",
  Body: fileBuffer,
  ContentType: "video/mp4",
}));
<!-- NexvorS3 responds automatically with HTTP 206 Partial Content & Accept-Ranges: bytes -->
